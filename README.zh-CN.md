# Task Hub（任务协作板）

一件任务，多个协作会话，一个共享的进度目录。

Task Hub 是给「需要多个会话一起推进」的活准备的面板。每件任务列出参与它的会话，并指向一个目录：每个人在里面写自己的进展文件。面板显示谁在跑、谁在等你、哪些文件已经写了，并且可以直接跳进某个会话。

它**不会**把消息发进别的会话。发信仍然是你在当前会话里明确做的一次动作，面板只帮你把那句话拼好。

## 能做什么

- **一件任务多个会话**：从 OpenChamber 里已打开的项目中添加会话，拖动排序，顺序会保存。
- **每件任务一个共享进度目录**：`README.md`（口径）、`SUMMARY.md`（已定结论）、每个会话一份 `progress-<id后6位>.md`。面板显示每个文件在不在、多大。
- **实时状态**：运行中、等你回答、空闲或找不到，和左侧栏用的是同一份活动状态。
- **点名字跳会话**：点一下会话名就打开那个聊天。
- **自动刷新**：3 秒一轮，编辑时可以关掉。

## 文件

全部在 `~/.task-hub/` 下：

- `tasks.json`：任务板本身，一件任务一条，带成员。面板和任意智能体读写同一份，所以终端、技能、别的工具也能直接改。
- `settings.json`：进度根目录。
- `<任务 id>/`：该任务的进度目录（`README.md`、`SUMMARY.md`、`progress-*.md`）。

## 安装

设置 → 扩展 → 粘贴文件夹、ZIP 或 Git 地址 → 添加。

需要批准两项：`sessions`（列项目和会话、打开聊天）和文件模式 `~/.task-hub/**`（读写进度目录）。

## 进度文件放在哪

每件任务二选一：

- **可读：家目录路径**。默认 `~/.task-hub/<任务 id>/`。根目录可以改到家目录下任意位置，但要和清单里的 `filesystem` 模式一致（默认 `~/.task-hub/**`）。这类目录面板能读，会显示文件状态。
- **只记录：任意路径**。比如 `D:\work\notes\task-123`。OpenChamber 读不到声明范围之外的路径，所以面板只显示和复制这个路径，并标一个 `external`；文件由你自己维护。

面板不会在可读目录之外创建任何文件，改任务也不会覆盖 `SUMMARY.md`。

## 明确不做

- 不向别的会话发信，不做本地服务，不起守护进程。
- 不显示每轮耗时：公开 SDK 拿不到 turn 的起点，所以只给状态，不给秒表。
- 不自动发现新会话，协作方由你手动添加。

## 开发

```bash
npm install
npx esbuild panel/src.js --bundle --format=iife --platform=browser --outfile=panel/main.js
```

`panel/main.js` 要提交进仓库：OpenChamber 安装时不会替你编译。
